# Shiv Trading

> **"Innovation, Construction & Satisfaction"**

A modern, production-ready digital showroom and architectural surface platform for **Shiv Trading**, based in Biratnagar, Nepal. The platform enables homeowners, architects, builders, and contractors to discover premium tiles, marble, granite, sanitaryware, and CP fittings, and experience them in realistic spaces using an interactive 3D surface visualizer.

---

## Key Features

- **Interactive 3D Surface Visualizer**:
  - Real-time room visualization (Living Room, Bathroom, Kitchen, Outdoor).
  - Material and texture switching (Statuario White, Warm Beige, Charcoal Vein, Speckled Granite).
  - Perspective-aligned floor surface mapping with Three.js and React Three Fiber.
  - Interactive adjustments for pattern scale, rotation angle, light intensity, and blend opacity.
- **Surface & Material Catalog**:
  - Structured categorization across Granites & Marbles, Floor Tiles, Wall Tiles, Sanitary & CP Fittings.
  - Sourcing transparency highlighting North Indian, Rajasthani, and South Indian natural stone.
  - Finish explorer covering High Gloss, Matt, Rustic, Satin, and Textured surfaces.
- **Trusted Brand Partners**:
  - Dedicated brand integration for industry leaders: **Somany**, **Plumber**, **Spera Vitrified LLP**, **SN (Since 1960)**, and **Parryware**.
  - Detailed product categorization and direct WhatsApp/enquiry links for each partner.
- **Customer Ratings & Testimonials**:
  - Aggregate satisfaction score (4.8 / 5.0) with category rating breakdowns.
  - Categorized client feedback across Residential, Commercial, and Renovation projects.
- **Contact & Showroom Hub**:
  - Direct clickable phone dialer (`9852023064`).
  - Dual dedicated WhatsApp chat buttons (`9816300663` and `9815344564`).
  - Showroom location details: *Biratnagar-13, Near Veterinary Hospital*.
  - Scannable website QR code for mobile handoff.
- **Bilingual Support**:
  - Seamless English and Nepali (नेपाली) language switcher.

## Technology Stack

- **Framework**: [TanStack Start](https://tanstack.com/start) & [TanStack Router](https://tanstack.com/router)
- **UI Library**: [React 19](https://react.dev/) (pinned to `19.2.0` for `@react-three/fiber` compatibility)
- **3D & Graphics**: [Three.js](https://threejs.org/) and [@react-three/fiber](https://docs.pmnd.rs/react-three-fiber)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/) with custom architectural typography and design tokens
- **Icons**: [Lucide React](https://lucide.dev/)
- **Bundler & Server**: [Vite](https://vitejs.dev/) with [Nitro](https://nitro.unjs.io/) server engine

## Getting Started

### Prerequisites

- Node.js `v20+` or `v22+` (or Bun)
- npm, pnpm, yarn, or bun

### Installation

Clone the repository and install dependencies:

```bash
# Using npm
npm install

# Or using bun
bun install
```

### Development Server

Start the local development server:

```bash
# Using npm
npm run dev

# Or using bun
bun run dev
```

The application will be accessible at `http://localhost:8080`.

### Production Build

Build the client bundles and server output:

```bash
# Using npm
npm run build

# Or using bun
bun run build
```

Preview the production build locally:

```bash
npm run preview
```
